Ultra-lightweight WordPress starter and fallback theme. No JavaScript, zero bloat, built for long-term stability.

== Description ==

BlankLite uses only long-stable classic theme APIs, one template and one tiny stylesheet. Suited as a fallback, a starter, or a canvas for page builders and headless setups.

== Installation ==

1. Upload the `blanklite` folder to `/wp-content/themes/`, or upload BlankLite.zip via Appearance > Themes > Add New.
2. Activate it, or keep it installed as your fallback theme.
3. Optional: add `define( 'CORE_UPGRADE_SKIP_NEW_BUNDLED', true );` to wp-config.php so core updates stop installing new yearly default themes.
