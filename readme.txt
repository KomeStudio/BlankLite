Ultra-lightweight classic starter and fallback theme. No JavaScript, no bloat.

== Description ==

BlankLite uses only long-stable classic theme APIs, a handful of tiny template files and one small stylesheet. Suited as a fallback, a starter, or a canvas for page builders and headless setups.

== Installation ==

1. Upload the `blanklite` folder to `/wp-content/themes/`, or upload the zip via Appearance > Themes > Add New.
2. Activate it, or keep it installed as your fallback theme.
3. Optional: add `define( 'CORE_UPGRADE_SKIP_NEW_BUNDLED', true );` to wp-config.php so core updates stop installing new yearly default themes.

== Frequently Asked Questions ==

= Does BlankLite load any JavaScript? =

No, except WordPress core's comment-reply script on posts with threaded comments enabled.

= Does BlankLite collect any data? =

No. It does not track, collect or send any data.
